# Supermart Grocery Sales & Profit Dashboard

## Project Overview
An Excel-based retail analytics dashboard developed to analyse sales, profitability, product categories, discount patterns and geographic performance for a Supermart grocery dataset.

## Key Analysis
- Monthly sales and profit trends
- Category-wise sales performance
- Top 10 sub-categories by sales
- Average profit across discount bands
- Sales and profit by region
- Top 10 cities by sales

## Key Performance Indicators
- Total Sales: ₹14,956,982
- Total Profit: ₹3,747,121
- Total Orders: 9,994
- Average Order Value: ₹1,496.60
- Profit Margin: 25.1%
- Average Discount: 22.7%

## Tools Used
Microsoft Excel, PivotTables, PivotCharts and data visualisation.

## Important Limitations
The dataset does not contain a product-name field, so product performance is analysed at the sub-category level. The State field contains only Tamil Nadu.
